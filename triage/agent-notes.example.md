# Agent notes — behavioural log

Maintained by `/triage`. Captures how you actually handle your inbox over
time, so future rounds prioritise better. On first run, /triage copies this
template to `agent-notes.md` (gitignored — it accumulates personal data).

## How to use this file
- /triage reads it BEFORE classifying and applies observed patterns silently
  (never echoed to you).
- After each round, /triage appends any new behavioural pattern: consistent
  skips, replies you always rewrite, recurring deferrals.
- /triage compacts `## Patterns observed` when it passes ~30 lines —
  repeating notes collapse into one summary line.
